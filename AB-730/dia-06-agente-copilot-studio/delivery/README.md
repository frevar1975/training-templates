# Delivery — Agente de demos en Copilot Studio

Guía para configurar, probar y explicar un agente Standard con tres fuentes de práctica ficticias.

## Contenido

- `Guia_del_instructor_Agente_Copilot_Studio.docx`: procedimiento clic a clic, texto sugerido para el instructor, instrucciones de conocimiento y tres prompts de prueba.
- `Resultados_esperados_y_validacion.md`: datos que deben aparecer y errores críticos que se deben detectar.

## Antes de la clase

1. Crear un agente Standard en Copilot Studio.
2. Copiar `template/04-instrucciones-del-agente.txt` al campo de instrucciones del agente.
3. Cargar por separado los tres archivos de ejemplo desde `template/` como conocimiento.
4. Esperar a que las fuentes estén disponibles.
5. Probar Atlas, Zapatería y Nébula con una conversación limpia para cada caso.

Los archivos de práctica son ficticios. El agente no consulta Outlook, WhatsApp ni un Excel en vivo y no modifica hojas de cálculo.
