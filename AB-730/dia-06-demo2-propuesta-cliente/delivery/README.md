# Guía de entrega — Demo 2

El paquete está preparado para explicar la síntesis multifuente y la creación de una presentación. La guía del instructor incluye objetivos, preparación, agenda, texto para narrar, prompts copiables, resultados esperados, criterios de validación, plan alternativo y cierre.

## Preparación

- Tener Copilot Chat, Word y PowerPoint disponibles en la cuenta de demostración.
- Descargar las tres fuentes de `template/`.
- Confirmar que se pueden adjuntar tres archivos en Copilot Chat.
- Verificar si PowerPoint ofrece creación desde un documento Word en ese tenant.
- No cargar documentación real del trabajo; este ejercicio usa datos enteramente ficticios.

## Producto esperado del alumno

- Una tabla de evidencia con fuente, nivel de certeza y datos faltantes.
- Una propuesta breve en Word revisada por la persona que la presenta.
- Una presentación de 8 diapositivas con alcance, alternativas y decisiones.

Consulta `Guia_del_instructor.docx` para seguir el ejercicio paso a paso.
