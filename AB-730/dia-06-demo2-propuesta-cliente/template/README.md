# Fuentes del ejercicio

Adjunta estos **tres archivos** a Copilot Chat para el análisis multifuente:

1. `01-brief-y-notas-descubrimiento.txt`
2. `02-correos-horizonte-logistica.txt`
3. `03-pricing-propuesta-horizonte.xlsx`

Todos los nombres, hechos y precios son ficticios. El libro de precios permite cambiar la duración del piloto y recalcula sus totales. La pestaña distingue cargos mensuales, costo único, impuestos excluidos y alcance ilustrativo.
