# Materiales ficticios para el Demo 3

- `07-rastreador-progreso-nebula-demo.xlsx`: libro de práctica con la tabla de resumen semanal calculada por fórmulas y el detalle de 50 tareas. El gráfico se crea en vivo durante el demo.
- `08-informe-semanal-nebula-base.docx`: documento Word base con la sección Métricas lista para insertar el gráfico y el análisis validado.

La tasa semanal es tareas completadas ÷ tareas planificadas para esa semana. El periodo contiene cinco semanas con 10 tareas planificadas por semana. La caída más visible ocurre del 12–18 al 19–25 de octubre. Los nombres, tareas, responsables, proyecto y estados son ficticios.
