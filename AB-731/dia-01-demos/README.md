# AB-731 Día 1 — Base reutilizable de demos

Este paquete maestro contiene los materiales en blanco para preparar ejercicios prácticos del AB-731. La base está en `template/`; se personaliza para cada centro y edición en el repositorio `training-delivery`.

## Contenido de `template/`

- `01-base-caso-atencion-cliente.txt`: caso de servicio con campos para completar y límites de uso.
- `02-base-registro.csv`: estructura vacía para datos de casos.
- `03-base-ficha-caso-uso.csv`: ficha de valor, viabilidad, riesgo y medición.
- `04-base-comparacion-costos.csv`: tabla para documentar supuestos de uso y costo.
- `05-base-ficha-revision-humana.csv`: lista de revisión antes de aprobar una respuesta.
- `06-estructura-prompt-reutilizable.txt`: prompt base con campos editables.

Completa copias de estos archivos con un escenario ficticio por cada edición. La secuencia sugerida cubre prueba de respuesta, analítica frente a generación, iteración de instrucciones, evaluación de casos de uso, costos y aprobación humana.
